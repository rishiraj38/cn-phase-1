================ F. HTTP caching - Cache-Control + ETag + 304 ================
--- 1) full request: server sends the body + caching headers
$ curl -sS -I --noproxy * https://app.team.test/api/info
HTTP/2 200 
server: nginx
date: Sat, 03 Oct 2026 19:19:14 GMT
content-type: application/json
content-length: 186
x-backend: A
cache-control: public, max-age=60
etag: "8e637a1a8a261c8e"
x-edge: mac2-nginx

--- 2) conditional request: 'I already have version "8e637a1a8a261c8e" - has it changed?'
$ curl -sS -I --noproxy * -H If-None-Match: "8e637a1a8a261c8e" https://app.team.test/api/info
HTTP/2 304 
server: nginx
date: Sat, 03 Oct 2026 19:19:14 GMT
content-length: 0
x-backend: A
cache-control: public, max-age=60
etag: "8e637a1a8a261c8e"
x-edge: mac2-nginx

--- 3) same conditional request again (probably the OTHER backend this time):
HTTP/2 304 
x-backend: B
etag: "8e637a1a8a261c8e"
=> 304 Not Modified + no body. Both backends hash the same content, so either can say 304.
